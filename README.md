# Сайт автосервиса и мастерской автомеханики 🚗🔧

![Превью сайта](./preview.png)

Современный адаптивный веб-сайт для автомастерской с интерактивными 3D-элементами, подбором услуг и модулем онлайн-записи. Проект решает проблему долгих телефонных консультаций и позволяет водителям оформить визит в два клика.

## ✨ Основные возможности
* **Интерактивный подбор услуг:** быстрый поиск работ по параметрам автомобиля и типу неисправности.
* **Онлайн-запись на ремонт:** простая форма бронирования визита на диагностику или ТО.
* **3D-анимация:** интерактивные объемные модели на базе Three.js для визуального акцента.
* **Адаптивность:** корректное отображение на смартфонах, планшетах и ПК.

## 🛠 Стек технологий
* HTML5 / CSS3
* JavaScript
* Three.js (3D-графика)
