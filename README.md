# apex-auto-project
Современный адаптивный сайт для автосервиса с интерактивной 3D-анимацией на Three.js. Главная цель — избавить водителей от долгих звонков. Внедрил умный подбор услуг по параметрам авто, прозрачный прайс и быструю онлайн-запись в два клика. Получился наглядный и удобный инструмент, который автоматизирует прием заявок.
